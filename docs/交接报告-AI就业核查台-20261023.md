## 4. 判定规则（唯一事实源：`tools/ai_lexicon.py`）

### 4.1 时间窗

- 只收 `posted_at >= 2026-06-01`；更早、或没有发布时间的**不导出、不计数**。
- 库内仍保留旧记录（状态 open），只是不出现在站点。

### 4.2 分级

| 级别 | 含义 | 判定 |
|---|---|---|
| build | 直接研发 AI | 标题命中强 AI 词 + 研发动作（算法/工程师/研发/架构/科学家） |
| adjacent | 直接支撑 AI | 强 AI 词 + 产品/运营/评测/治理/战略；或相邻词（搜推、MLOps、算力、推理平台、数据标注、AI 治理、提示词） |
| none | 其余 | 状态改 `excluded`，不物理删除 |

强 AI 词示例：算法、大模型、机器学习、深度学习、多模态、AIGC、生成式、具身智能、自动驾驶、智能体、基座模型、LLM、CV、NLP、推荐/搜索/广告算法、语音、知识图谱、Transformer。

### 4.3 排除（即使带 AI 也不进）

- 职能岗：招聘、人事、人力资源、HRBP、财务、税务、法务、采购、行政、销售、商务、渠道、品牌、公关、门店、配送、客服、内容运营、客户经理、投资、融资。
- 括号限定语：`（AI 驱动）`、`（AI 工具）`、`（AI 辅助）`、`（AI 赋能）` —— 这类是「用 AI 工具」，不是 AI 岗。
- 机器人硬件（结构/电子/机械/嵌入式）不因「机器人」二字入库。

### 4.4 AI 业务岗的归属

- 商业化 / 合规 / 负责人 / 经理 / 总监 / TPM / Program Manager：命中强 AI 词但没有算法/工程师词 → 判 **adjacent**（标注 `business:`），不算研发。
- 同时带「算法/工程师/研发」→ 仍判 build。

### 4.5 存活（`tools/liveness.py`）

| 结果 | 含义 | 处置 |
|---|---|---|
| active | 当日接口/页面能读到投递入口 | 正常展示 |
| uncertain | 403/429/反爬/页面无投递入口 | **不判死**，只记录，下次复检 |
| expired | 404/410、关闭横幅、截止日期已过、美团接口 data=null | 转 `closed`，写 `job_changes` |

- 美团必须走详情接口（页面是 SPA，假 ID 也会渲染出「立即投递」）。
- 连续 14 天没再采集到、且读不到投递入口 → `stale`（默认不展示）。

### 4.6 去重

- 标题规范化（空格/全半角/括号）+ 描述相似度 ≥ 0.62 合并，保留最新，状态 `merged`。
